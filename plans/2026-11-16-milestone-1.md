# Milestone 1: Identity Across One A2A Hop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A request signed in as north.mgr reaches the orchestrator on Azure Container Apps, crosses one A2A hop to an internal data-agent, and the data-agent's tool calls Microsoft Graph with a fresh on-behalf-of (OBO) token for that user. Tokens from the wrong caller are rejected at every hop.

**Architecture:** The `shared` package holds the only token check (PyJWT against Entra's keys: issuer, tenant, `aud`, `scp`, `azp` allow-list), a pure-ASGI middleware that stores the validated caller in a `ContextVar`, and an OBO client whose credential is a federated credential trusting the service's user-assigned managed identity (no secrets). The data-agent is an a2a-sdk 1.x server; a2a-sdk runs the executor inside a copy of the request's context, so the tool reads the caller from the `ContextVar`. The orchestrator is a small Starlette chat API whose outbound A2A adapter does the OBO exchange per call. Both run in one Container Apps environment with peer-to-peer encryption; only the orchestrator has external ingress. The data-agent repo is the service template: later services copy its layout, workflows and Dockerfile. App registrations come from an idempotent `az` script; Azure resources from Bicep; settings from `.env` (D-026).

**Tech Stack:** Python 3.12, uv 0.13.6, a2a-sdk 1.3.0, Starlette 1.10.0, uvicorn 0.54.0, httpx 0.28.1, PyJWT 2.15.1, msal 1.39.0, azure-identity 1.27.0, pytest 9.2.0, ruff 0.17.3; Azure Container Apps (API 2026-07-01), user-assigned managed identities, Entra app registrations (v2 tokens), Microsoft Graph; GitHub Actions publishing public images to ghcr.io.

## Review Focus

1. **OBO with a managed-identity client assertion in Azure:** Learn documents managed identity as a federated credential but doesn't show OBO with it explicitly. A reasonable owner expects the first live call to either work or fail with a readable Entra error code. Pinned by Task 9 check 1, plus the troubleshooting table there.
2. **Plain `http://<app-name>` between apps with `allowInsecure: false` and peer-to-peer encryption:** Learn recommends the short name, but only a third-party test confirms it works with `allowInsecure: false`. The expected behavior is that the hop works and the traffic is encrypted. Pinned by Task 9 check 1, with the fallback in its troubleshooting table.
3. **Cold starts:** both apps scale to zero, so the first call wakes two containers. The first request must succeed, just slowly, and not time out. Task 9 uses a 120-second client timeout, and the orchestrator's A2A call allows 60 seconds for the data-agent to wake.
4. **A real token from an app that isn't on the allow-list:** the orchestrator must answer 403, and the reason must be the allow-list, not a missing consent. Pinned by Task 9 check 2. The unlisted app has a consent grant, so it really does get a valid token.
5. **Reaching the data-agent from the internet:** internal ingress must refuse it (404 or no route). Pinned by Task 9 check 4.

```python
"""Validates Entra v2 access tokens: signature, issuer, tenant, audience, scope and calling app."""

from collections.abc import Callable
from dataclasses import dataclass
from typing import Any

import jwt

ALGORITHMS = ["RS256"]
REQUIRED_CLAIMS = ["exp", "nbf", "iss", "aud", "tid", "oid", "azp", "ver"]


class TokenRejected(Exception):
    """401 for a token we can't trust, 403 for a trusted token without the right scope or caller."""

    def __init__(self, status: int, reason: str) -> None:
        super().__init__(reason)
        self.status = status
        self.reason = reason


@dataclass(frozen=True)
class Caller:
    oid: str
    tid: str
    azp: str
    scopes: frozenset[str]


@dataclass(frozen=True)
class TokenPolicy:
    issuer: str
    tenant_id: str
    audience: str
    required_scope: str
    allowed_callers: frozenset[str]


SigningKey = Callable[[str], Any]


class TokenValidator:
    def __init__(self, policy: TokenPolicy, signing_key: SigningKey) -> None:
        self._policy = policy
        self._signing_key = signing_key

    def validate(self, token: str) -> Caller:
        policy = self._policy
        try:
            unverified = jwt.decode(token, options={"verify_signature": False})
        except jwt.PyJWTError:
            raise TokenRejected(401, "malformed token") from None
        # Checked before any key lookup, so foreign tokens never trigger a JWKS fetch.
        if unverified.get("iss") != policy.issuer:
            raise TokenRejected(401, "wrong issuer")
        try:
            claims = jwt.decode(
                token,
                self._signing_key(token),
                algorithms=ALGORITHMS,
                audience=policy.audience,
                issuer=policy.issuer,
                options={"require": REQUIRED_CLAIMS},
            )
        except jwt.PyJWTError as error:
            raise TokenRejected(401, f"invalid token ({type(error).__name__})") from None
        if claims["ver"] != "2.0" or claims["tid"] != policy.tenant_id:
            raise TokenRejected(401, "wrong token version or tenant")
        scopes = frozenset(str(claims.get("scp", "")).split())
        if policy.required_scope not in scopes:
            raise TokenRejected(403, "missing scope")
        if claims["azp"] not in policy.allowed_callers:
            raise TokenRejected(403, "calling app not allowed")
        return Caller(oid=claims["oid"], tid=claims["tid"], azp=claims["azp"], scopes=scopes)


def entra_validator(
    tenant_id: str,
    audience: str,
    allowed_callers: frozenset[str],
    required_scope: str = "access_as_user",
) -> TokenValidator:
    """Validator for real Entra tokens. The only one a deployed service may use."""
    jwks = jwt.PyJWKClient(
        f"https://login.microsoftonline.com/{tenant_id}/discovery/v2.0/keys", lifespan=3600
    )
    policy = TokenPolicy(
        issuer=f"https://login.microsoftonline.com/{tenant_id}/v2.0",
        tenant_id=tenant_id,
        audience=audience,
        required_scope=required_scope,
        allowed_callers=allowed_callers,
    )
    return TokenValidator(policy, lambda token: jwks.get_signing_key_from_jwt(token).key)
```

```python
"""Local token issuer for tests and ADAPTERS=fake. A deployed service never trusts it (D-019)."""

import time
import uuid

import jwt
from cryptography.hazmat.primitives.asymmetric import rsa

from margin_copilot_shared.security.tokens import TokenPolicy, TokenValidator

LOCAL_TENANT = "11111111-1111-1111-1111-111111111111"


class LocalIssuer:
    def __init__(self, tenant_id: str = LOCAL_TENANT) -> None:
        self.tenant_id = tenant_id
        self.issuer = f"https://local-issuer.invalid/{tenant_id}/v2.0"
        self._key = rsa.generate_private_key(public_exponent=65537, key_size=2048)

    def issue(
        self,
        *,
        audience: str,
        azp: str,
        scp: str = "access_as_user",
        oid: str | None = None,
        lifetime: int = 600,
        drop: tuple[str, ...] = (),
        **overrides: object,
    ) -> str:
        now = int(time.time())
        claims: dict[str, object] = {
            "iss": self.issuer,
            "aud": audience,
            "azp": azp,
            "scp": scp,
            "oid": oid or str(uuid.uuid4()),
            "tid": self.tenant_id,
            "ver": "2.0",
            "iat": now,
            "nbf": now,
            "exp": now + lifetime,
        }
        claims.update(overrides)
        for name in drop:
            claims.pop(name, None)
        return jwt.encode(claims, self._key, algorithm="RS256")

    def validator(
        self,
        *,
        audience: str,
        allowed_callers: frozenset[str],
        required_scope: str = "access_as_user",
    ) -> TokenValidator:
        policy = TokenPolicy(
            issuer=self.issuer,
            tenant_id=self.tenant_id,
            audience=audience,
            required_scope=required_scope,
            allowed_callers=allowed_callers,
        )
        public_key = self._key.public_key()
        return TokenValidator(policy, lambda _token: public_key)
```

```python
"""The validated caller of the current request, readable anywhere in its async context."""

from collections.abc import Iterator
from contextlib import contextmanager
from contextvars import ContextVar
from dataclasses import dataclass, field

from margin_copilot_shared.security.tokens import Caller


@dataclass(frozen=True)
class RequestContext:
    caller: Caller
    token: str = field(repr=False)


_current: ContextVar[RequestContext] = ContextVar("margin_copilot_request")


def current_request() -> RequestContext:
    try:
        return _current.get()
    except LookupError:
        raise RuntimeError("no authenticated request in this context") from None


@contextmanager
def request_scope(context: RequestContext) -> Iterator[None]:
    reset = _current.set(context)
    try:
        yield
    finally:
        _current.reset(reset)
```

```python
"""ASGI middleware: every request needs a valid bearer token before it reaches the app."""

import json

from starlette.authentication import SimpleUser
from starlette.types import ASGIApp, Receive, Scope, Send

from margin_copilot_shared.security.context import RequestContext, request_scope
from margin_copilot_shared.security.tokens import TokenRejected, TokenValidator


class AuthMiddleware:
    def __init__(
        self,
        app: ASGIApp,
        validator: TokenValidator,
        public_paths: frozenset[str] = frozenset(),
    ) -> None:
        self.app = app
        self.validator = validator
        self.public_paths = public_paths

    async def __call__(self, scope: Scope, receive: Receive, send: Send) -> None:
        if scope["type"] != "http" or scope["path"] in self.public_paths:
            await self.app(scope, receive, send)
            return
        token = _bearer_token(scope)
        try:
            if token is None:
                raise TokenRejected(401, "missing bearer token")
            caller = self.validator.validate(token)
        except TokenRejected as rejected:
            await _reject(send, rejected)
            return
        scope["user"] = SimpleUser(caller.oid)
        with request_scope(RequestContext(caller=caller, token=token)):
            await self.app(scope, receive, send)


def _bearer_token(scope: Scope) -> str | None:
    for name, value in scope["headers"]:
        if name == b"authorization":
            scheme, _, token = value.decode("latin-1").partition(" ")
            if scheme.lower() == "bearer" and token.strip():
                return token.strip()
    return None


async def _reject(send: Send, rejected: TokenRejected) -> None:
    error = "insufficient_scope" if rejected.status == 403 else "invalid_token"
    body = json.dumps({"error": rejected.reason}).encode()
    await send(
        {
            "type": "http.response.start",
            "status": rejected.status,
            "headers": [
                (b"content-type", b"application/json"),
                (b"www-authenticate", f'Bearer error="{error}"'.encode()),
                (b"content-length", str(len(body)).encode()),
            ],
        }
    )
    await send({"type": "http.response.body", "body": body})
```

```python
"""On-behalf-of exchange: trade the caller's token for one addressed to the next service."""

from collections.abc import Callable, Sequence
from typing import Any

import msal
from azure.identity import ManagedIdentityCredential

TOKEN_EXCHANGE_SCOPE = "api://AzureADTokenExchange/.default"


class OboFailed(Exception):
    def __init__(self, error: str, claims: str | None = None) -> None:
        super().__init__(error)
        self.error = error
        self.claims = claims


def managed_identity_assertion(managed_identity_client_id: str) -> Callable[[], str]:
    """Client assertion from a user-assigned managed identity trusted by the app (no secrets)."""
    credential = ManagedIdentityCredential(client_id=managed_identity_client_id)
    return lambda: credential.get_token(TOKEN_EXCHANGE_SCOPE).token


class OboClient:
    def __init__(
        self,
        tenant_id: str,
        client_id: str,
        client_assertion: Callable[[], str],
        app: Any = None,
    ) -> None:
        self._app = app or msal.ConfidentialClientApplication(
            client_id,
            authority=f"https://login.microsoftonline.com/{tenant_id}",
            client_credential={"client_assertion": client_assertion},
        )

    def exchange(self, user_token: str, scopes: Sequence[str]) -> str:
        # ponytail: msal doesn't cache OBO results, so every call hits Entra; add a cache keyed
        # by (token hash, scopes) if latency matters.
        result = self._app.acquire_token_on_behalf_of(user_token, list(scopes))
        if "access_token" not in result:
            raise OboFailed(result.get("error", "unknown_error"), result.get("claims"))
        return result["access_token"]
```

```python
from data_agent.application.whoami import Directory, whoami


class DataAgentExecutor(AgentExecutor):
    def __init__(self, directory: Directory) -> None:
        self._directory = directory

    async def execute(self, context: RequestContext, event_queue: EventQueue) -> None:
        await event_queue.enqueue_event(new_text_message(await whoami(self._directory)))

    async def cancel(self, context: RequestContext, event_queue: EventQueue) -> None:
        raise NotImplementedError("data-agent replies in one message; nothing to cancel")

    return AgentCard(
        name="data-agent",
        description="Answers questions from Riad Market sales data as the signed-in user.",
        version="0.1.0",
        default_input_modes=["text/plain"],
        default_output_modes=["text/plain"],
        capabilities=AgentCapabilities(streaming=False),
        supported_interfaces=[
            AgentInterface(protocol_binding="JSONRPC", url=public_url, protocol_version="1.0")
        ],
        skills=[
            AgentSkill(
                id="whoami",
                name="Who am I",
                description="Reports the signed-in user as the directory sees them.",
                tags=["identity"],
            )
        ],
    )

    handler = DefaultRequestHandler(
        agent_executor=DataAgentExecutor(directory),

    return Starlette(
        routes=[*create_agent_card_routes(card), *create_jsonrpc_routes(handler, "/")],
```

```python
import os

import httpx
from margin_copilot_shared.security.obo import OboClient, managed_identity_assertion

from margin_copilot_shared.testing.issuer import LocalIssuer

from data_agent.adapters.outbound.directory import FakeDirectory, GraphDirectory


def create_app() -> Starlette:
    env = os.environ
    adapters = env["ADAPTERS"]
    public_url = env.get("PUBLIC_URL", "http://localhost:8000/")
    if adapters == "azure":
        tenant_id, client_id = env["TENANT_ID"], env["CLIENT_ID"]
        callers = frozenset(env["ALLOWED_CALLERS"].split(","))
        obo = OboClient(tenant_id, client_id, managed_identity_assertion(env["AZURE_CLIENT_ID"]))
        directory = GraphDirectory(obo, httpx.AsyncClient(timeout=10))
        return create_a2a_app(directory, entra_validator(tenant_id, client_id, callers), public_url)

            audience="data-agent", allowed_callers=frozenset({"orchestrator"})
        )
        return create_a2a_app(FakeDirectory(), validator, public_url)
    raise ValueError(f"ADAPTERS must be azure or fake, not {adapters!r}")
```

```python
"""DataAgent port adapters: A2A client with a fresh OBO token per call, and a fake."""

import asyncio
from collections.abc import Callable, Sequence

import httpx
from a2a.client import Client, ClientCallContext, ClientConfig, create_client
from a2a.client.errors import A2AClientError
from a2a.helpers import get_message_text, new_text_message
from a2a.types import Role, SendMessageRequest
from margin_copilot_shared.security.context import current_request
from margin_copilot_shared.security.obo import OboFailed

from orchestrator.application.ask import DataAgentUnavailable

MAX_REPLY_CHARS = 8000
Exchange = Callable[[str, Sequence[str]], str]


class A2ADataAgent:
    def __init__(self, url: str, scope: str, exchange: Exchange, http: httpx.AsyncClient) -> None:
        self._url = url
        self._scope = scope
        self._exchange = exchange
        self._http = http
        self._client: Client | None = None

    async def ask(self, question: str) -> str:
        try:
            token = await asyncio.to_thread(self._exchange, current_request().token, [self._scope])
        except OboFailed as failed:
            raise DataAgentUnavailable(f"token exchange failed: {failed.error}") from None
        try:
            return await self._send(question, token)
        except (A2AClientError, httpx.HTTPError) as failed:
            raise DataAgentUnavailable(f"data-agent call failed: {failed}") from None

    async def _send(self, question: str, token: str) -> str:
        if self._client is None:
            self._client = await create_client(
                self._url, client_config=ClientConfig(httpx_client=self._http, streaming=False)
            )
        request = SendMessageRequest(message=new_text_message(question, role=Role.ROLE_USER))
        context = ClientCallContext(service_parameters={"Authorization": f"Bearer {token}"})
        async for event in self._client.send_message(request, context=context):
            if event.WhichOneof("payload") == "message":
                reply = get_message_text(event.message)
                if len(reply) > MAX_REPLY_CHARS:
                    raise DataAgentUnavailable("data-agent reply too large")
                return reply
        raise DataAgentUnavailable("data-agent sent no reply")


class FakeDataAgent:
    async def ask(self, question: str) -> str:
        return f"fake data-agent sees user {current_request().caller.oid}"
```

```python
"""Chat API: POST /chat {"question": ...} -> {"answer": ...}, behind the token middleware."""

import json
import logging

from margin_copilot_shared.security.middleware import AuthMiddleware
from margin_copilot_shared.security.tokens import TokenValidator
from starlette.applications import Starlette
from starlette.middleware import Middleware
from starlette.requests import Request
from starlette.responses import JSONResponse
from starlette.routing import Route

from orchestrator.application.ask import DataAgent, DataAgentUnavailable, ask

MAX_BODY_BYTES = 16_384
MAX_QUESTION_CHARS = 2_000
log = logging.getLogger(__name__)


def create_http_app(data_agent: DataAgent, validator: TokenValidator) -> Starlette:
    async def chat(request: Request) -> JSONResponse:
        body = await request.body()
        if len(body) > MAX_BODY_BYTES:
            return JSONResponse({"error": "request too large"}, status_code=413)
        try:
            payload = json.loads(body)
        except ValueError:
            return JSONResponse({"error": "body must be JSON"}, status_code=400)
        question = payload.get("question") if isinstance(payload, dict) else None
        if not isinstance(question, str) or not question.strip():
            return JSONResponse({"error": "question is required"}, status_code=400)
        if len(question) > MAX_QUESTION_CHARS:
            return JSONResponse({"error": "question too long"}, status_code=413)
        try:
            answer = await ask(question, data_agent)
        except DataAgentUnavailable as unavailable:
            log.warning("data agent unavailable: %s", unavailable)
            return JSONResponse({"error": "data-agent unavailable"}, status_code=502)
        return JSONResponse({"answer": answer})

    return Starlette(
        routes=[Route("/chat", chat, methods=["POST"])],
        middleware=[Middleware(AuthMiddleware, validator=validator)],
    )
```

```python
import os

import httpx
from margin_copilot_shared.security.obo import OboClient, managed_identity_assertion
from margin_copilot_shared.security.tokens import entra_validator
from margin_copilot_shared.testing.issuer import LocalIssuer
from starlette.applications import Starlette

from orchestrator.adapters.inbound.http_api import create_http_app
from orchestrator.adapters.outbound.data_agent import A2ADataAgent, FakeDataAgent


def create_app() -> Starlette:
    env = os.environ
    adapters = env["ADAPTERS"]
    if adapters == "azure":
        tenant_id, client_id = env["TENANT_ID"], env["CLIENT_ID"]
        callers = frozenset(env["ALLOWED_CALLERS"].split(","))
        obo = OboClient(tenant_id, client_id, managed_identity_assertion(env["AZURE_CLIENT_ID"]))
        data_agent = A2ADataAgent(
            env["DATA_AGENT_URL"],
            env["DATA_AGENT_SCOPE"],
            obo.exchange,
            httpx.AsyncClient(timeout=60),
        )
        return create_http_app(data_agent, entra_validator(tenant_id, client_id, callers))
    if adapters == "fake":
        # A fresh in-memory key per process: nobody outside this process can mint a token for it.
        validator = LocalIssuer().validator(
            audience="orchestrator", allowed_callers=frozenset({"cli"})
        )
        return create_http_app(FakeDataAgent(), validator)
    raise ValueError(f"ADAPTERS must be azure or fake, not {adapters!r}")
```

```bash
#!/usr/bin/env bash
# Verifies what entra-apps.sh creates. Exits 1 and lists what's missing or wrong.
set -uo pipefail
. "$(dirname "$0")/config.sh"
: "${NAME_PREFIX:?Set NAME_PREFIX (see .env.example)}" "${RESOURCE_GROUP:?Set RESOURCE_GROUP (see .env.example)}"

GRAPH=https://graph.microsoft.com/v1.0

fail() { echo "$1"; problems=1; }

for name in orchestrator data-agent cli cli-unlisted; do
  ids=($(az ad app list --filter "displayName eq '$NAME_PREFIX-$name'" --query '[].appId' -o tsv))
  if [ ${#ids[@]} -ne 1 ]; then fail "expected one app named $NAME_PREFIX-$name, found ${#ids[@]}"; continue; fi
  app=${ids[0]}
  sp=$(az ad sp show --id "$app" --query id -o tsv 2>/dev/null)
  [ -n "$sp" ] || fail "missing service principal: $name"
  printf -v "sp_${name//-/_}" '%s' "$sp"
  case $name in
    orchestrator|data-agent)
      [ "$(az ad app show --id "$app" --query api.requestedAccessTokenVersion -o tsv)" = 2 ] || fail "$name: tokens are not v2"
      [ "$(az ad app show --id "$app" --query 'identifierUris[0]' -o tsv)" = "api://$app" ] || fail "$name: identifier URI is not api://<appId>"
      [ "$(az ad app show --id "$app" --query "length(api.oauth2PermissionScopes[?value=='access_as_user' && isEnabled])" -o tsv)" = 1 ] \
        || fail "$name: scope access_as_user missing or disabled"
      subject=$(az identity show -g "$RESOURCE_GROUP" -n "id-$NAME_PREFIX-$name" --query principalId -o tsv)
      fic=$(az ad app federated-credential list --id "$app" \
        --query "[?name=='managed-identity'] | [0] | join('|', [issuer, subject, audiences[0]])" -o tsv)
      [ "$fic" = "https://login.microsoftonline.com/$tenant_id/v2.0|$subject|api://AzureADTokenExchange" ] \
        || fail "$name: federated credential missing or not trusting id-$NAME_PREFIX-$name"
      ;;
    cli|cli-unlisted)
      [ "$(az ad app show --id "$app" --query 'publicClient.redirectUris[0]' -o tsv)" = "http://localhost" ] \
        || fail "$name: public client redirect http://localhost missing"
      ;;
  esac
done

graph_sp=$(az ad sp show --id 00000003-0000-0000-c000-000000000000 --query id -o tsv)
check_grant() {  # client-sp resource-sp scope label
  [ -n "$1" ] && [ -n "$2" ] || { fail "grant $4: service principal missing"; return; }
  scope=$(az rest --method GET --url "$GRAPH/oauth2PermissionGrants?\$filter=clientId%20eq%20'$1'" \
    --query "value[?resourceId=='$2' && consentType=='AllPrincipals'].scope | [0]" -o tsv)

[ "$problems" -eq 0 ] && echo "entra apps check: OK"
```

`infra/scripts/entra-apps.sh`:
```bash
#!/usr/bin/env bash
# Creates the app registrations for the spike (names from NAME_PREFIX in .env):
#   <prefix>-orchestrator, <prefix>-data-agent: APIs with v2 tokens, scope access_as_user, and a
#     federated credential trusting the service's managed identity (no secrets);
#   <prefix>-cli, <prefix>-cli-unlisted: public clients for the live check (only cli is allow-listed);
# plus their service principals and tenant-wide consent grants. Safe to run again.
set -euo pipefail
. "$(dirname "$0")/config.sh"
: "${NAME_PREFIX:?Set NAME_PREFIX (see .env.example)}" "${RESOURCE_GROUP:?Set RESOURCE_GROUP (see .env.example)}"

GRAPH=https://graph.microsoft.com/v1.0
tenant_id=$(az account show --query tenantId -o tsv)

ensure_app() {  # display-name -> appId
  local id
  # Exact name match: --display-name matches by prefix.
  id=$(az ad app list --filter "displayName eq '$1'" --query '[0].appId' -o tsv)
  if [ -z "$id" ]; then
    id=$(az ad app create --display-name "$1" --sign-in-audience AzureADMyOrg --query appId -o tsv)
    echo "created app: $1" >&2
  fi
  echo "$id"
}

patch_app() {  # appId json
  local object_id
  object_id=$(az ad app show --id "$1" --query id -o tsv)
  az rest --method PATCH --url "$GRAPH/applications/$object_id" \
    --headers Content-Type=application/json --body "$2" >/dev/null
}

configure_api() {  # appId
  local scope_id
  scope_id=$(az ad app show --id "$1" --query "api.oauth2PermissionScopes[?value=='access_as_user'].id | [0]" -o tsv)
  [ -n "$scope_id" ] || scope_id=$(uuidgen | tr '[:upper:]' '[:lower:]')
  patch_app "$1" "{\"identifierUris\":[\"api://$1\"],\"api\":{\"requestedAccessTokenVersion\":2,\
\"oauth2PermissionScopes\":[{\"id\":\"$scope_id\",\"value\":\"access_as_user\",\"type\":\"User\",\
\"isEnabled\":true,\"adminConsentDisplayName\":\"Access as the signed-in user\",\
\"adminConsentDescription\":\"Call this service as the signed-in user.\",\
\"userConsentDisplayName\":\"Access as you\",\"userConsentDescription\":\"Call this service as you.\"}]}}"
}

configure_public_client() {  # appId
  patch_app "$1" '{"isFallbackPublicClient":true,"publicClient":{"redirectUris":["http://localhost"]}}'
}

ensure_sp() {  # appId label -> service principal object id
  local id
  id=$(az ad sp show --id "$1" --query id -o tsv 2>/dev/null || true)
  if [ -z "$id" ]; then
    id=$(az ad sp create --id "$1" --query id -o tsv)
    echo "created service principal: $2" >&2
  fi
  echo "$id"
}

ensure_fic() {  # appId managed-identity-name label
  local subject current body
  subject=$(az identity show -g "$RESOURCE_GROUP" -n "$2" --query principalId -o tsv)
  body="{\"name\":\"managed-identity\",\"issuer\":\"https://login.microsoftonline.com/$tenant_id/v2.0\",\
\"subject\":\"$subject\",\"audiences\":[\"api://AzureADTokenExchange\"]}"
  current=$(az ad app federated-credential list --id "$1" --query "[?name=='managed-identity'].subject | [0]" -o tsv)
  if [ -z "$current" ]; then
    az ad app federated-credential create --id "$1" --parameters "$body" >/dev/null
    echo "created federated credential: $3" >&2
  elif [ "$current" != "$subject" ]; then
    az ad app federated-credential update --id "$1" --federated-credential-id managed-identity --parameters "$body" >/dev/null
    echo "updated federated credential: $3" >&2
  fi
}

ensure_grant() {  # client-sp resource-sp scope label
  local existing
  existing=$(az rest --method GET --url "$GRAPH/oauth2PermissionGrants?\$filter=clientId%20eq%20'$1'" \
    --query "value[?resourceId=='$2' && consentType=='AllPrincipals'].scope | [0]" -o tsv)
  if [ -z "$existing" ]; then
    az rest --method POST --url "$GRAPH/oauth2PermissionGrants" --headers Content-Type=application/json \
      --body "{\"clientId\":\"$1\",\"consentType\":\"AllPrincipals\",\"resourceId\":\"$2\",\"scope\":\"$3\"}" >/dev/null
    echo "granted: $4 ($3)" >&2
  fi
}

orchestrator=$(ensure_app "$NAME_PREFIX-orchestrator")
data_agent=$(ensure_app "$NAME_PREFIX-data-agent")
cli=$(ensure_app "$NAME_PREFIX-cli")
unlisted=$(ensure_app "$NAME_PREFIX-cli-unlisted")

configure_api "$orchestrator"
configure_api "$data_agent"
configure_public_client "$cli"
configure_public_client "$unlisted"

orchestrator_sp=$(ensure_sp "$orchestrator" orchestrator)
data_agent_sp=$(ensure_sp "$data_agent" data-agent)
cli_sp=$(ensure_sp "$cli" cli)
unlisted_sp=$(ensure_sp "$unlisted" cli-unlisted)
graph_sp=$(az ad sp show --id 00000003-0000-0000-c000-000000000000 --query id -o tsv)

ensure_fic "$orchestrator" "id-$NAME_PREFIX-orchestrator" orchestrator
ensure_fic "$data_agent" "id-$NAME_PREFIX-data-agent" data-agent

ensure_grant "$cli_sp" "$orchestrator_sp" access_as_user "cli -> orchestrator"
ensure_grant "$unlisted_sp" "$orchestrator_sp" access_as_user "cli-unlisted -> orchestrator"
ensure_grant "$orchestrator_sp" "$data_agent_sp" access_as_user "orchestrator -> data-agent"
ensure_grant "$data_agent_sp" "$graph_sp" User.Read "data-agent -> Microsoft Graph"

echo "entra apps: done"
```

- [ ] **Step 2: The live check**

`evals/live/identity_hop.py`:
```python
# /// script
# requires-python = ">=3.12,<3.13"
# dependencies = [
#   "httpx==0.28.1",
#   "msal==1.39.0",
#   "margin-copilot-shared @ git+https://github.com/margin-copilot/shared@v0.1.0",
# ]
# ///
"""Milestone 1 live check: identity across one A2A hop, run on the laptop (D-019).

Reads evals/.env (written by infra/scripts/spike-env.sh). The browser opens twice: sign in as the
first test user both times, first through the allow-listed CLI app, then through the unlisted one.
"""

import pathlib
import sys

import httpx
import msal
from margin_copilot_shared.testing.issuer import LocalIssuer

QUESTION = {"question": "who am I?"}


def load_env(path: pathlib.Path) -> dict[str, str]:
    pairs = (line.split("=", 1) for line in path.read_text().splitlines() if "=" in line)
    return {key.strip(): value.strip() for key, value in pairs if not key.startswith("#")}


def sign_in(env: dict[str, str], client_id: str) -> str:
    app = msal.PublicClientApplication(
        client_id, authority=f"https://login.microsoftonline.com/{env['TENANT_ID']}"
    )
    result = app.acquire_token_interactive([env["ORCHESTRATOR_SCOPE"]], prompt="select_account")
    if "access_token" not in result:
        sys.exit(f"sign-in failed: {result.get('error')}: {result.get('error_description')}")
    return result["access_token"]


def main() -> int:
    env = load_env(pathlib.Path(__file__).resolve().parent.parent / ".env")
    chat = f"{env['ORCHESTRATOR_URL']}/chat"
    results = []

    def check(name: str, passed: bool, detail: str) -> None:
        results.append(passed)
        print(f"{'PASS' if passed else 'FAIL'}  {name}: {detail}")

    with httpx.Client(timeout=120) as http:
        token = sign_in(env, env["CLI_CLIENT_ID"])
        response = http.post(chat, json=QUESTION, headers={"Authorization": f"Bearer {token}"})
        expected = f"data-agent sees {env['EXPECTED_DISPLAY_NAME']}"
        answer = response.json().get("answer") if response.status_code == 200 else None
        check(
            "signed-in user crosses the A2A hop",
            answer == expected,
            f"{response.status_code} {response.text[:200]}",
        )

        token = sign_in(env, env["UNLISTED_CLIENT_ID"])
        response = http.post(chat, json=QUESTION, headers={"Authorization": f"Bearer {token}"})
        check(
            "token from an unlisted app is rejected",
            response.status_code == 403,
            f"{response.status_code} {response.text[:200]}",
        )

        local = LocalIssuer(tenant_id=env["TENANT_ID"]).issue(
            audience=env["ORCHESTRATOR_CLIENT_ID"], azp=env["CLI_CLIENT_ID"]
        )
        response = http.post(chat, json=QUESTION, headers={"Authorization": f"Bearer {local}"})
        check(
            "locally signed token is rejected",
            response.status_code == 401,
            f"{response.status_code} {response.text[:200]}",
        )

        try:
            card = f"https://{env['DATA_AGENT_FQDN']}/.well-known/agent-card.json"
            status = str(http.get(card, timeout=30).status_code)
        except httpx.HTTPError as error:
            status = type(error).__name__
        check("data-agent is unreachable from the internet", status != "200", status)

    return 0 if all(results) else 1


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# Security model

How a user's identity travels through Margin Copilot, and what each service checks. Code: `shared` (token check, request context, OBO), `orchestrator`, `data-agent`. Setup: app registrations and managed identities from scripts in the infra repo; every name is configurable (D-026).

## One request, end to end

```mermaid
sequenceDiagram
  autonumber
  participant U as User (browser sign-in)
  participant C as Client app (allow-listed)
  participant O as orchestrator (external ingress)
  participant E as Entra ID
  participant D as data-agent (internal ingress)
  participant G as Microsoft Graph
  U->>C: sign in (MFA)
  C->>E: token for orchestrator / access_as_user
  C->>O: POST /chat + token (aud = orchestrator)
  O->>O: check signature, issuer, tenant, aud, scp, azp
  O->>E: OBO: user token + managed-identity assertion
  E-->>O: token for data-agent (same user)
  O->>D: A2A SendMessage + new token (aud = data-agent)
  D->>D: same checks; caller stored for this request
  D->>E: OBO from the tool: token for Graph User.Read
  D->>G: GET /me as the user
  G-->>D: display name
  D-->>O: "data-agent sees <name>"
  O-->>C: answer
```

## What every service checks

The `shared` token check is the only one in the project:
- The signature is RS256 against Entra's published keys.
- The issuer is our tenant's v2 issuer, and `tid` matches.
- `ver` is 2.0.
- `aud` is this service's app ID.
- `scp` contains `access_as_user`.
- The calling app (`azp`) is on this service's allow-list: the client app for the orchestrator, the orchestrator for the data-agent.

The issuer is checked before any key lookup, so a foreign token never makes us fetch keys. An untrusted token gets 401; a trusted token with the wrong scope or caller gets 403.

## Tokens never travel further than one hop

Each service exchanges the incoming token for a new one addressed to the next service (OBO), so a stolen token only works where it was meant to go. Microsoft Graph tokens are forwarded and never parsed.

## No secrets

Each confidential app authenticates to Entra with a federated credential that trusts its own user-assigned managed identity (issuer = the tenant's v2 endpoint, subject = the identity's principal ID, audience `api://AzureADTokenExchange`). There are no client secrets or certificates.

## The caller inside a service

`AuthMiddleware` stores the validated caller and token in a request-scoped context variable. a2a-sdk (from 1.2.3) runs the agent executor inside a copy of the request's context, so a tool reads the caller with `current_request()`, and concurrent requests never see each other. Authorization facts come from the validated token only, never from the message or a model.

## Network

All apps share one Container Apps environment with peer-to-peer encryption on. Only the orchestrator has external ingress; the data-agent answers only inside the environment (404 from outside). Container Apps authenticates apps to each other but doesn't authorize them; the token checks above do.

## Tests and the local issuer

`LocalIssuer` signs tokens with a key that lives only in the test process, and services trust it only when `ADAPTERS=fake`. Unit tests cover each rejection case. The live check (`evals/live/identity_hop.py`) proves the deployed path:
- A real user crosses the hop.
- A real token from an unlisted app gets 403.
- A locally signed token gets 401.
- The data-agent can't be reached from outside.

## Known limits

- There is no VNet or private endpoint (cost); every endpoint still requires an Entra token.
- OBO results aren't cached, so each hop calls Entra once per request.
- The agent card (`/.well-known/agent-card.json`) is served without a token, but only inside the environment (D-028).
````
