# Milestone 2: Eval Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Write the eval cases before the features: about 40 golden and scope questions plus adversarial cases, run in CI against the whole system on fake adapters. Cases for milestones already done must pass; every later case must fail, and only because the system answered differently from what the case expects.

**Architecture:**
- **Cases are TOML data** in the `evals` repo. Each case is tagged with the first milestone where it must pass.
- **The harness builds the system in one process:** the orchestrator, the A2A hop and the data-agent, with fake outbound adapters and tokens from `LocalIssuer`. A local stand-in plays Entra's OBO.
- **The harness judges each response deterministically:** status, required and forbidden text, refusal kind, agents called, and citations.
- **pytest runs each case.** Cases for future milestones are `xfail(strict=True, raises=CaseFailed)`:
  - a crash fails CI;
  - an early pass fails CI, so the case gets promoted;
  - a case that only checks for absent text is rejected by the loader, because it would pass on a system that says nothing.
- **The response fields the cases expect** (`answer`, `refusal`, `agents`, `citations`) become the chat response contract that later milestones implement.

**Tech Stack:** Python 3.12, uv 0.13.6, pytest 9.2.0 + pytest-asyncio 1.4.1, httpx 0.28.1, PyJWT 2.15.1, stdlib `tomllib`; `orchestrator` and `data-agent` installed from git tags, `margin-copilot-shared` v0.1.1.

## Review Focus

1. **Golden wording too strict:** a correct future answer may phrase a fact differently ("6 %", "January 19") and fail. A reasonable owner expects a failing golden case to mean a wrong answer. The `|` alternatives help. Each milestone that activates cases reviews their wording against real answers before bumping `CURRENT_MILESTONE`. This plan has no test for it; it's a known limit, recorded in D-029.
2. **Contract drift:** services could name the response fields differently from the cases (`agents`, `citations`, `refusal`). D-029 fixes the names. The shared Pydantic contract and its contract test arrive in milestone 7; until then the cases are the contract.
3. **Version drift:** evals pins service tags, so CI here tests the tagged versions, not `main`. Each milestone that changes a service tags it and bumps the pins in the same milestone (Task 5 shows the pattern).
4. **Golden cases need a model:** CI has no model today. Milestone 4 decides whether CI calls Foundry keylessly (GitHub OIDC) or whether golden cases run only in the live suite. Recorded as an open question in `roadmap.md`.
5. **A crash in a future case must fail CI, not count as an expected failure:** pinned by Task 5, step 5, which breaks the system on purpose and expects all cases to fail.

```python
"""Loads eval cases and personas from TOML and rejects malformed ones before anything runs."""

import tomllib
from dataclasses import dataclass, fields
from pathlib import Path

CASES_DIR = Path(__file__).resolve().parents[2] / "cases"
KINDS = frozenset({"plumbing", "golden", "scope", "adversarial"})
REFUSALS = frozenset({"out_of_scope", "no_access", "no_data"})
TOKENS = frozenset(
    {
        "valid",
        "none",
        "unlisted_app",
        "data_agent_audience",
        "expired",
        "missing_scope",
        "other_issuer",
    }
)
AGENTS = frozenset({"data-agent", "policy-agent", "action-agent"})
LAST_MILESTONE = 12


class CaseError(ValueError):
    pass


@dataclass(frozen=True)
class Persona:
    name: str
    oid: str
    groups: tuple[str, ...]


@dataclass(frozen=True)
class Expect:
    status: int = 200
    contains: tuple[str, ...] = ()  # each entry: alternatives separated by "|"
    not_contains: tuple[str, ...] = ()
    refusal: str | None = None
    agents: tuple[str, ...] = ()
    no_agents: bool = False
    citations: tuple[str, ...] = ()
    not_citations: tuple[str, ...] = ()


@dataclass(frozen=True)
class Case:
    id: str
    kind: str
    milestone: int
    persona: str
    question: str
    expect: Expect
    token: str = "valid"
    raw_body: str | None = None
    repeat: int = 1
    note: str = ""


def load_personas(path: Path = CASES_DIR / "personas.toml") -> dict[str, Persona]:
    data = tomllib.loads(path.read_text())
    return {
        name: Persona(name=name, oid=raw["oid"], groups=tuple(raw["groups"]))
        for name, raw in data["persona"].items()
    }


def load_cases(
    directory: Path = CASES_DIR, personas: dict[str, Persona] | None = None
) -> list[Case]:
    personas = personas if personas is not None else load_personas(directory / "personas.toml")
    cases: list[Case] = []
    for path in sorted(directory.glob("*.toml")):
        if path.name == "personas.toml":
            continue
        for raw in tomllib.loads(path.read_text()).get("case", []):
            cases.append(_case(raw, personas, path.name))
    ids = [case.id for case in cases]
    duplicates = sorted({case_id for case_id in ids if ids.count(case_id) > 1})
    if duplicates:
        raise CaseError(f"duplicate case ids: {', '.join(duplicates)}")
    return cases


def _case(raw: dict, personas: dict[str, Persona], source: str) -> Case:
    where = f"{source} case {raw.get('id', '?')}"
    raw = dict(raw)
    expect_raw = raw.pop("expect", {})
    _check_keys(raw, {f.name for f in fields(Case)} - {"expect"}, where)
    _check_keys(expect_raw, {f.name for f in fields(Expect)}, f"{where} expect")
    expect = Expect(**{k: tuple(v) if isinstance(v, list) else v for k, v in expect_raw.items()})
    case = Case(expect=expect, **raw)
    problems = []
    if case.kind not in KINDS:
        problems.append(f"kind {case.kind!r}")
    if not 1 <= case.milestone <= LAST_MILESTONE:
        problems.append(f"milestone {case.milestone}")
    if case.persona not in personas:
        problems.append(f"persona {case.persona!r}")
    if case.token not in TOKENS:
        problems.append(f"token {case.token!r}")
    if expect.refusal is not None and expect.refusal not in REFUSALS:
        problems.append(f"refusal {expect.refusal!r}")
    if not set(expect.agents) <= AGENTS:
        problems.append(f"agents {sorted(set(expect.agents) - AGENTS)}")
    # Negative checks alone pass on a system that says nothing, so a 200 case needs a positive one.
    if expect.status == 200 and not (
        expect.contains or expect.agents or expect.citations or expect.refusal
    ):
        problems.append("a 200 case needs a positive check (contains, agents, citations, refusal)")
    if problems:
        raise CaseError(f"{where}: invalid {', '.join(problems)}")
    return case


def _check_keys(raw: dict, allowed: set[str], where: str) -> None:
    unknown = sorted(set(raw) - allowed)
    if unknown:
        raise CaseError(f"{where}: unknown keys {', '.join(unknown)}")
```

`evals/src/margin_evals/judge.py`:
```python
"""Compares one chat API response with a case's expectations."""

from margin_evals.cases import Case


class CaseFailed(AssertionError):
    """The system answered, but not as the case expects. The only way a pending case may fail."""


def judge(case: Case, status: int, body: dict | None) -> list[str]:
    expect = case.expect
    if status != expect.status:
        return [f"status {status}, expected {expect.status}"]
    if status != 200:
        return []
    body = body if isinstance(body, dict) else {}
    answer = str(body.get("answer", "")).lower()
    refusal = body.get("refusal")
    agents = set(body.get("agents") or [])
    citations = set(body.get("citations") or [])
    problems = []
    for item in expect.contains:
        if not any(alt.strip().lower() in answer for alt in item.split("|")):
            problems.append(f"answer lacks {item!r}")
    for item in expect.not_contains:
        if item.lower() in answer:
            problems.append(f"answer contains {item!r}")
    if expect.refusal is not None and refusal != expect.refusal:
        problems.append(f"refusal {refusal!r}, expected {expect.refusal!r}")
    if expect.refusal is None and expect.contains and refusal:
        problems.append(f"unexpected refusal {refusal!r}")
    if missing := sorted(set(expect.agents) - agents):
        problems.append(f"agents not called: {', '.join(missing)}")
    if expect.no_agents and agents:
        problems.append(f"agents called: {', '.join(sorted(agents))}")
    if missing := sorted(set(expect.citations) - citations):
        problems.append(f"missing citations: {', '.join(missing)}")
    if forbidden := sorted(set(expect.not_citations) & citations):
        problems.append(f"forbidden citations: {', '.join(forbidden)}")
    return problems
```

```python
outbound adapters and tokens from a local issuer. No network, no Azure."""

import json

import httpx
import jwt
from data_agent.adapters.inbound.a2a_server import create_a2a_app
from data_agent.adapters.outbound.directory import FakeDirectory
from margin_copilot_shared.security.obo import OboFailed
from margin_copilot_shared.security.tokens import TokenRejected, TokenValidator
from margin_copilot_shared.testing.issuer import LocalIssuer
from orchestrator.adapters.inbound.http_api import create_http_app
from orchestrator.adapters.outbound.data_agent import A2ADataAgent

from margin_evals.cases import Case, Persona

ORCHESTRATOR = "eval-orchestrator"
DATA_AGENT = "eval-data-agent"
CLI = "eval-cli"
DATA_AGENT_SCOPE = f"api://{DATA_AGENT}/access_as_user"
DATA_AGENT_URL = "http://data-agent/"
OTHER_TENANT = "22222222-2222-2222-2222-222222222222"
CARRIED_CLAIMS = ("groups",)


class LocalObo:
    """Stands in for Entra OBO: checks the incoming token, mints one for the next service."""

    def __init__(
        self,
        issuer: LocalIssuer,
        incoming: TokenValidator,
        client_id: str,
        audiences: dict[str, str],
    ) -> None:
        self._issuer = issuer
        self._incoming = incoming
        self._client_id = client_id
        self._audiences = audiences

    def exchange(self, user_token: str, scopes: list[str]) -> str:
        if len(scopes) != 1 or scopes[0] not in self._audiences:
            raise OboFailed("invalid_scope")
        try:
            caller = self._incoming.validate(user_token)
        except TokenRejected:
            raise OboFailed("invalid_grant") from None
        claims = jwt.decode(user_token, options={"verify_signature": False})
        carried = {name: claims[name] for name in CARRIED_CLAIMS if name in claims}
        return self._issuer.issue(
            audience=self._audiences[scopes[0]], azp=self._client_id, oid=caller.oid, **carried
        )


class System:
    def __init__(self) -> None:
        self.issuer = LocalIssuer()
        user_tokens = self.issuer.validator(audience=ORCHESTRATOR, allowed_callers=frozenset({CLI}))
        data_agent_app = create_a2a_app(
            FakeDirectory(),
            self.issuer.validator(audience=DATA_AGENT, allowed_callers=frozenset({ORCHESTRATOR})),
            DATA_AGENT_URL,
        )
        self.obo = LocalObo(self.issuer, user_tokens, ORCHESTRATOR, {DATA_AGENT_SCOPE: DATA_AGENT})
        data_agent = A2ADataAgent(
            DATA_AGENT_URL,
            DATA_AGENT_SCOPE,
            self.obo.exchange,
            httpx.AsyncClient(transport=httpx.ASGITransport(app=data_agent_app)),
        )
        app = create_http_app(data_agent, user_tokens)
        self.client = httpx.AsyncClient(
            transport=httpx.ASGITransport(app=app), base_url="http://orchestrator"
        )

    def token(self, persona: Persona, variant: str) -> str | None:
        claims = {"oid": persona.oid, "groups": list(persona.groups)}
        match variant:
            case "valid":
                return self.issuer.issue(audience=ORCHESTRATOR, azp=CLI, **claims)
            case "none":
                return None
            case "unlisted_app":
                return self.issuer.issue(audience=ORCHESTRATOR, azp="unlisted-cli", **claims)
            case "data_agent_audience":
                return self.issuer.issue(audience=DATA_AGENT, azp=CLI, **claims)
            case "expired":
                return self.issuer.issue(audience=ORCHESTRATOR, azp=CLI, lifetime=-60, **claims)
            case "missing_scope":
                return self.issuer.issue(
                    audience=ORCHESTRATOR, azp=CLI, scp="other.scope", **claims
                )
            case "other_issuer":
                return LocalIssuer(OTHER_TENANT).issue(audience=ORCHESTRATOR, azp=CLI, **claims)
        raise ValueError(f"unknown token variant {variant!r}")

    async def ask(self, case: Case, persona: Persona) -> tuple[int, dict | None]:
        headers = {"content-type": "application/json"}
        token = self.token(persona, case.token)
        if token is not None:
            headers["authorization"] = f"Bearer {token}"
        if case.raw_body is not None:
            content = case.raw_body.encode()
        else:
            content = json.dumps({"question": case.question * case.repeat}).encode()
        response = await self.client.post("/chat", content=content, headers=headers)
        try:
            body = response.json()
        except ValueError:
            body = None
        return response.status_code, body
```

`evals/tests/test_suite.py`:
```python
"""The eval suite. Cases for milestones up to CURRENT_MILESTONE must pass. Later cases must fail
with CaseFailed (the system answered, but not as expected); a crash or an early pass fails CI."""

import pytest

from margin_evals import CURRENT_MILESTONE
from margin_evals.cases import load_cases, load_personas
from margin_evals.judge import CaseFailed, judge
from margin_evals.system import System

PERSONAS = load_personas()


def cases():
    for case in load_cases(personas=PERSONAS):
        marks = []
        if case.milestone > CURRENT_MILESTONE:
            reason = f"needs milestone {case.milestone}"
            marks.append(pytest.mark.xfail(raises=CaseFailed, strict=True, reason=reason))
        yield pytest.param(case, id=case.id, marks=marks)


@pytest.mark.parametrize("case", list(cases()))
async def test_case(case):
    status, body = await System().ask(case, PERSONAS[case.persona])
    if problems := judge(case, status, body):
        raise CaseFailed("; ".join(problems))
```

```markdown
### D-029 Eval cases first, gated by milestone; the chat response contract
- **Decision:** Eval cases are TOML data in the `evals` repo. Each names the first milestone where it must pass.
  - pytest runs every case against the system on fake adapters.
  - Cases up to `CURRENT_MILESTONE` must pass.
  - Later cases are `xfail(strict=True, raises=CaseFailed)`. They must fail only because the system answered differently from the case; a crash or an early pass fails CI.
  - A 200 case needs at least one positive check. Negative checks alone pass on a system that says nothing.
- **Response contract:** `POST /chat` returns JSON with these fields; services implement them by milestone 7:
  - `answer` (text);
  - `refusal`: `null`, `out_of_scope`, `no_access` or `no_data` (D-013);
  - `agents`: the agents called in this turn (`data-agent`, `policy-agent`, `action-agent`);
  - `citations`: clause IDs such as `PP-04 §3.2`.
- **Why:** The brief asks for the harness and failing tests first. Strict xfail makes "fails for the right reasons" checkable, and turns each finished milestone into a list of cases that must go green.
- **Known limits:**
  - Golden wording may be stricter than a correct answer; each milestone reviews its cases against real answers before bumping `CURRENT_MILESTONE`.
  - Golden cases need a model, and milestone 4 decides whether CI gets one keylessly or golden cases run only in the live suite.
  - Groundedness is checked through required facts and citations. Model-judged scores (azure-ai-evaluation: groundedness, tool-call accuracy) join the live suite in milestone 7.
```
